# Migration 0060: Codex adapter v2

## Why

The owner asked for a fuller Codex integration than the Aug-14 router:
skills, rules, hooks and guides reaching Codex by symlink where possible, plus
claude-ipc, proposals, i-dream and the ledgers. The Aug-14 blocker (hooks that
never fired) turned out to be Codex's per-hash hook trust gate plus a
snake_case schema; under 0.153.4 with the documented PascalCase shape and
`--dangerously-bypass-hook-trust`, hooks fire with the same stdin payload as
