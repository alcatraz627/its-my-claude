out as a wall of text: table cells and paragraphs hundreds of characters long.

A note during an edit was not enough: clanky-opus got it three times on
DIRECTIONS.md (2026-10-22), decided the file was for agents, kept writing, and
told the owner it had written a better doc. So the check now runs again when
the turn ends, on the file as it stands. While a doc written this turn still
fails, the turn may not end (twice), and never on a reply that calls that doc
better or fixed. If the agent ends the turn anyway, the owner is told.

A third failure is a doc that is hard to skim: dense paragraphs, lines spliced
with semicolons, runs of sentences that only name code and paths. Those checks
are shared with the GitHub prose gate (prose_readability.py), with a few more
allowed here because a doc is longer than a comment.

Runtime contract:
  doc-voice-gate.py          PostToolUse on Write/Edit/MultiEdit: note + record

non-agent `reader:` (that includes a file under `.claude/`). Skips `archive/`,

a file outside `docs/` only; under `docs/` only the owner's list does

reply at the end of the turn points the owner at it by its full path, because

#
# When the agent's final message asserts how a subsystem works — authority /
# source-of-truth / call-chain / an external tool's behavior / a dependency claim —
# and this turn shows NO grounding (no in-message cite AND no Read/Grep of the named
# subject), the gate fires. A fire forces the agent to SYNC WITH THE FILESYSTEM
# before proceeding.
#
# Philosophy (the user's, verbatim): "the extra time or tool calls are worthwhile
# for correctness even if nothing comes out of the procedure, because it's much
# worse when things are MISSED." So this gate's value is FORCED GROUNDING, not
# true-positive yield:
#   - A false FIRE (the claim was actually right) is ACCEPTABLE when a grounding
#     read was possible and simply wasn't done — the sync is the point.
#   - A fire is BAD only when grounding is IMPOSSIBLE (person/team owns; external
#     behavior already looked up) or ALREADY DONE (subject read/edited this turn,
#     a file:line cited, a run verified). Those are the carve-outs.
# Anti-paralysis comes from LOOP-SAFETY (block once per claim sentence, then step
# aside) — NOT from silencing. The block is kept because a nudge forces nothing.
#
# Backstop for atone `structural-claim-without-reading-code` (S3, #1 recurring).
#

#   ①  a claim-shape matches the final message (authority incl owns/mints; and the
#      ship-gated callchain/extmech/manifest shapes when enabled)
#   ②  no clearing carve-out in the message: file:line/[UNVERIFIED] (E1), a
#      verify-verb+runtime (E3), person/team-owns homograph (E5), or a meta-quote
#      of the pattern/hook itself (META)
#   ③  read-gate (this turn only):

# A segment that is only the dump verb (plus a listing flag), ending at a
# separator, a pipe, a redirect or the end of the command.
DUMP='(^|[;&|(]|\n)[[:space:]]*(/usr/bin/)?(env|printenv|set|export([[:space:]]+-p)?|declare[[:space:]]+-[xp]+|typeset[[:space:]]+-x)[[:space:]]*($|[;&|)>]|\n)'
# Process inspectors that print each process's environment: pm2's detail
# verbs, ps with the macOS environment flags (-e, -E or the e keyword), and
# docker inspect.
PROC='(^|[;&|(]|\n)[[:space:]]*(pm2[[:space:]]+(jlist|prettylist|env|show|describe)|ps[[:space:]]+(-[a-zA-Z]*[eE][a-zA-Z]*|[a-z]*e[a-z]*)([[:space:]]|$)|docker[[:space:]]+(container[[:space:]]+)?inspect)'

# gcloud commands whose whole output is a credential. Fine when the token is
# captured, in $( ) or backticks or redirected to a file; refused when it
# would print.
TOKEN_CMD='(print-[a-z]+-token|config-helper)'
# A gcloud token command at a command position. `$(` is not a command
# position: that is the captured form.
GCLOUD_AT="(^|[;&|]|\n|[^\$]\()[[:space:]]*gcloud[[:space:]][^;&|)]*${TOKEN_CMD}[^;&|)]*"
# Standard output sent to a file (not stderr alone, not a descriptor).
STDOUT_TO_FILE='(^|[[:space:]]|1)>>?[[:space:]]*[^&>[:space:]]'

leaks_token() {
  local seg
  while IFS= read -r seg; do
    [ -n "$seg" ] || continue
    printf '%s' "$seg" | grep -qE "$STDOUT_TO_FILE" || return 0
  done < <(printf '%s' "$cmd" | sed -E 's/&>/ 1>/g' | grep -oE "$GCLOUD_AT")
  # A captured token handed straight to echo or printf is printed anyway.
  printf '%s' "$raw" | grep -qE "(^|[;&|(]|\n)[[:space:]]*(echo|printf)[[:space:]][^;&|]*(\\\$\(|\`)[[:space:]]*gcloud[[:space:]][^)\`]*${TOKEN_CMD}" && return 0
  return 1
}

# The command ssh runs on the other machine is a command like any other, even
# though it is quoted in the local line.
remote_dumps() {
  local remote
  while IFS= read -r remote; do

    printf '%s' "$remote" | grep -qE "$DUMP|$PROC" && return 0
  done < <(printf '%s' "$raw" | python3 "$HOME/.claude/scripts/hooks/ssh-remote-cmd.py" 2>/dev/null)
  return 1
}

#!/usr/bin/env bash
# guard-pr-title-tags.sh — refuses a `gh pr create` (or `gh pr edit --title`)
# whose title lacks the tags the repo asks for.
#
# Agent-raised PRs cost Slack noise and bot-review money, so the owner wants a
# tag in the title ([noslack], sometimes [nobot]) at the moment the PR opens,
# when it is too late to take the notice back (rules/pr-nobot-noslack-codex-review.md).
# The tags are a per-repo call, so the hook asks the repo first:
#
#   1. A line `PR-TITLE-TAGS: [noslack] [nobot]` in the repo's .claude/pr-title-tags,
#      CLAUDE.md or AGENTS.md (first file that has one wins). `none` means the
#      repo wants no tag. `allow-fill` lets `--fill` through without a title.
#   2. Otherwise the global default: [noslack] only. [nobot] stays a judgment
#      call per PR, so it is never demanded by default.
#
# The repo is the command's own: `-R/--repo owner/name` (found as a local clone
# under ~/Code by its origin remote) or the working directory, after any
# `cd` earlier in the command. A repo with no local clone gets the default.
# Any spelling of a tag counts ([no-slack], [NoSlack]). `--fill` without
# `--title` is refused because the title then comes from the commit message and
# the tag cannot be promised.
#
# PreToolUse on Bash. Fails open if jq, python3 or the shell scanner is missing.
# Mute: touch ~/.claude/.no-pr-title-tags-gate  (machine-wide)  or PR_TITLE_TAGS_OFF=1

set -u

def git(d, *args):
    try:
        r = subprocess.run(["git", "-C", d, *args], capture_output=True, text=True, timeout=5)
        return r.stdout.strip() if r.returncode == 0 else ""
    except Exception:
        return ""


def toplevel(d):
    return git(d, "rev-parse", "--show-toplevel") if os.path.isdir(d) else ""


def origin_slug(d):
    url = git(d, "remote", "get-url", "origin")
    m = re.search(r"([\w.-]+/[\w.-]+?)(?:\.git)?/?$", url)
    return m.group(1).lower() if m else ""
